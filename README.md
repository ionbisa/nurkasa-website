# CV NurKasa Jaya Pertiwi

Website resmi CV NurKasa Jaya Pertiwi.

## Tentang Perusahaan

CV NurKasa Jaya Pertiwi merupakan perusahaan yang bergerak dalam bidang:

- Jasa Konstruksi
- Perdagangan Barang
- Leveransir
- Jasa Service dan Maintenance AC

## Layanan

### Jasa Konstruksi

- Pembangunan rumah dan gedung
- Renovasi
- Pemasangan pagar
- Pemasangan canopy

### AC Service & Maintenance

- Instalasi AC
- Service AC
- Cleaning AC
- Preventive Maintenance
- Perawatan dan pemeliharaan AC
